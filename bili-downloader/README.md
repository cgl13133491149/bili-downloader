# B站分P智能下载管理器（Bili Downloader）

> 当前整理版本：V5.0.0  
> 项目类型：浏览器用户脚本（Userscript）  
> 适用站点：Bilibili 视频播放页  
> 发布目标：GitHub + Greasy Fork

## 项目简介

B站分P智能下载管理器用于在 Bilibili 普通投稿视频播放页识别分P，并由用户选择本地目录，按分P标题保存视频轨道和音频轨道。界面采用右下角悬浮入口，支持折叠面板、文件清单、运行日志、单文件下载和批量下载。

## 主要功能（以实际测试结果为准）

- 识别当前 BV 视频的分P列表。
- 按 `001_原标题`、`002_原标题`……的格式命名。
- 将视频轨道与音频轨道分别保存为 `.mp4`、`.m4a` 文件。
- 扫描用户选择的本地目录，识别已有文件并跳过。
- 支持单独下载某一分P的视频轨道或音频轨道。
- 支持批量下载缺失文件。
- 支持每次扫描时重新选择根目录。
- 悬浮图标、可折叠管理器、可折叠分P清单和日志。

## 重要说明：V5.0 当前技术边界

1. **MP4 与 M4A 是分离的 DASH 轨道。** 当前实现分别保存视频轨道和音频轨道，不会把两者合并成带声音的单个 MP4。视频轨道文件即使使用 `.mp4` 扩展名，也可能是无音频的分段 MP4 流。
2. **音频编码与扩展名必须匹配。** 只有实际返回 AAC/MP4 音频轨道时才应保存为 `.m4a`。若接口返回 Opus/WebM 音频，不应仅通过改扩展名伪装成 M4A。
3. **浏览器跨域限制可能影响下载。** DASH CDN 是否允许页面脚本读取响应流，取决于 CDN 的 CORS 响应头、登录状态和浏览器环境。需在 Edge、Chrome 中实际验证。
4. **画质与编码选择受账号、视频、接口返回值影响。** 配置中的画质 ID 不保证每个视频都可用。
5. **断点续传尚未实现。** 停止或网络中断后，需检查目标文件是否残留、是否完整；不要把仅存在且大小大于 0 的文件一律视为完整下载。
6. **目前不应标注为“稳定版”或宣称已兼容所有视频。** 发布前应按下方测试清单验证，并根据测试结果更新版本说明。

## 安装

1. 在 Chrome 或 Edge 安装并启用 Tampermonkey（或兼容的用户脚本管理器）。
2. 从 Greasy Fork 安装正式发布版本，或在 GitHub 下载 `.user.js` 文件后手动导入。
3. 打开 Bilibili 视频播放页。
4. 点击页面右下角悬浮图标打开管理器。
5. 点击“识别分P”。
6. 点击“扫描文件”并选择本地保存根目录。扫描操作会在每次点击时重新请求选择目录。
7. 单文件下载：展开“分P文件清单”，点击对应分P的 MP4 或 M4A 项。
8. 批量下载：点击“下载全部缺失”。

## 文件命名

每个分P使用三位序号和原标题：

```text
视频总标题/
├── 001_原标题.mp4
├── 001_原标题.m4a
├── 002_原标题.mp4
├── 002_原标题.m4a
└── ...
```

注：此结构表示分别保存的视频轨道和音频轨道，并不表示 MP4 已经封装音频。

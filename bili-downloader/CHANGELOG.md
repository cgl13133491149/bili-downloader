# 更新日志

本项目采用简化的版本记录格式。

## [5.0.0] - 尚未正式发布

### 新增
- 右下角悬浮图标入口，默认折叠管理器。
- 管理器面板支持展开与收起。
- 分P文件清单和运行日志可独立折叠。
- 支持按分P单独下载视频轨道或音频轨道。
- 支持批量下载缺失文件。
- 支持扫描本地目录并跳过已存在文件。
- 扫描时可重新选择本地根目录。
- 按 `001_原标题` 格式生成文件名。

### 修复 / 整理
- 悬浮图标和折叠按钮事件绑定调整到 DOM 创建之后。
- 扫描按钮增加扫描状态锁，并在异常后恢复按钮状态。
- 扫描时重新选择文件夹的行为纳入使用说明。

### 已知限制
- 视频轨道与音频轨道分别保存，尚未合并为带声音的单个 MP4。
- 音频流必须确认编码为 AAC/MP4 才能安全命名为 `.m4a`。
- CDN 跨域响应可能阻止浏览器脚本读取下载流。
- 当前文件存在性检查不能证明文件完整。
- 尚未完成跨浏览器、跨编码、长视频和中断恢复的完整回归测试。

### 发布状态
- **预发布整理版**，不应在完成测试前宣称为稳定版。
